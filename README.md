# 💼 Cartera

Bu proje **React** ve **TypeScript** kullanılarak geliştirilmiş, kullanıcı girişi, haber akışı, döviz verileri ve profil bilgilerini içeren bir finans uygulamasıdır.  
Uygulama modern React yapısı, component tabanlı mimarisi ve API entegrasyonları ile örnek bir dashboard yapısı sunar.
<br />

## 🚀 Özellikler

- 🔐 **Firebase Authentication** ile giriş yap / kayıt ol işlemleri  
- ✅ **Yup** ile form doğrulama kontrolleri  
- 📰 **News API** üzerinden ekonomi haberlerinin dinamik olarak çekilmesi  
- 💱 **FreeCurrencyAPI** üzerinden döviz kurlarının anlık gösterimi  
- 💳 **Fake API** kullanılarak oluşturulan kullanıcı ve bakiye verileri  
- 👤 **Profil Sayfası** — kullanıcı bilgileri API'den alınarak gösterilir  
- ⚙️ **TypeScript** ile güçlü tip kontrolü  
- 🧩 Component, slice, store ve config yapısı ile temiz kod organizasyonu

<br />


##  🧾 API Kullanımı
🔹 News API  
URL: https://newsapi.org/v2/top-headlines?category=business&apiKey=YOUR_KEY  
Kullanım: Ekonomi haberlerini listelemek için kullanılır.  
   
🔹 FreeCurrencyAPI   
URL: https://api.freecurrencyapi.com/v1/latest?apikey=YOUR_KEY  
Kullanım: Döviz kurları listesini almak için kullanılır.
